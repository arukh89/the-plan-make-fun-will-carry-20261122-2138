A 280-character plan an AI agent can carry out itself to turn $100 into the most money in 30 days: find Shopify stores already paying for Meta ads whose mobile pages are slow, send each a free teardown naming the leak, sell a $49 fix-list audit (PDF in 24h), then offer a $199 fix — 9 audits at 3% conversion plus 2 fixes comes to about $839 against $40 of tools, repeated with fresh stores.

## Run it

```sh
python3 main.py
```

This writes the plan to `/output/entry.txt` (override with the `ENTRY_OUTPUT` environment variable).
